#### 面向对象

**把事物和它的行为打包在一起，做成一个模板，用模板造实例**.

 - 用相机做比喻：
 - - 属性（有什么）：型号、分辨率、图片存储路径
 - - 方法（能干啥）：拍照、保存图片、调整亮度


```python
# 模板：类 class
class Camera:
    def __init__(self, res):
        self.resolution = res  # 属性：分辨率
    
    def take_photo(self): # 方法：拍照
        print(f"用{self.resolution}分辨率拍照")

# 根据模板造出一个真实的相机（实例）
cam1 = Camera("1080P")
cam1.take_photo()

# `class` = 图纸（模板）
# `cam1` = 根据图纸造出来的真实相机对象
# `self` = 对象自己，相机访问自己的分辨率、自己的拍照功能。

```

1. **封装**：把属性、方法打包在类里面，内部细节藏起来，外面只需要调用。

> 
> 就像你用相机，不用懂内部电路，直接点拍照就行。

2. **继承**：旧模板改一改，造出新版模板，复用旧功能。

> 
> 普通相机 → 继承升级成工业相机，保留拍照，新增缺陷检测。

3. **多态**：不同对象，同一个名字的方法，各自有自己的实现。

> 
> 相机。保存 ()、图片类。保存 ()，都叫 save，但底层逻辑不一样。


#### 抽象

**定这个类必须有哪些方法，但不写方法里面代码，交给子类去实现**


>举例子：
>规定【图像采集设备】都必须有 `capture()`采集图像这个功能，但不写怎么采集。
>可以是摄像头、可以是读本地图片。
>摄像头子类：capture 就是调用相机拍图
>图片子类：capture 就是读取文件夹图片

```python
from abc import ABC, abstractmethod

# 抽象类：定标准
class ImageDevice(ABC):
    @abstractmethod
    def capture(self):
        # 只声明，里面不写代码
        pass

# 子类继承抽象类，必须实现capture
class UsbCamera(ImageDevice):
    def capture(self):
        print("USB摄像头采集图像")

cam = UsbCamera()
cam.capture()


```

### 总结

- 做数据集类、图像预处理类，大量用类和封装（前面讲迭代器、魔法方法就用到了）
- 抽象类适合写**通用接口**：比如不管是摄像头、视频文件、本地图片，统一写一个`get_frame()`拿图像，换数据源不用大面积改代码
- 抽象类不能直接造对象，只能当模板给别人继承。
你不能直接造出一个 “图像采集设备”，只能造摄像头 / 图片读取器
